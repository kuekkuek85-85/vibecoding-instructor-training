# 연수 당일 운영 안내

2026-08-11(화) 15:30~17:30 · 강사 1명 + 수강생 4명

## 0. 시작 전 (10분)

1. `.env.local` 값이 모두 채워져 있는지 확인 (`.env.local.example` 참고)
2. Firebase 콘솔 → Firestore Database → 규칙 탭에 `firestore.rules` 내용 붙여넣고 게시
3. `npm run dev` (또는 배포 주소 접속)
4. `/admin?key=<ADMIN_KEY>` 접속 → 수강생 4명 이름·과목 입력 → **새 세션 만들기**
5. 수강생에게 알려 줄 것: 사이트 **루트 주소만** (`/`). 키·세션 ID 불필요

## 1. 진행 순서

강사 대시보드 상단의 단계 버튼을 눌러 전원 화면을 동시에 넘긴다.

| 단계 | 강사가 할 일 | 수강생 화면 |
|---|---|---|
| 1 대기 | 강의 · 화면 공유 | 과학자 문장이 돌아가는 대기 화면 |
| 2 설계 | "소재를 하나 고르고 **검증 기준**만 직접 쓰세요" | 설계서 7칸 (6칸 사전 채움) |
| 3 설계 검토 | AI → 자기 → 동료 순서로 안내 | 검토 3종 + 승인 대기 |
| — 게이트 | 카드마다 **게이트 승인** 클릭 | 🔒 해제 |
| 4 제작 | 프롬프트 복사 → 캔바 코드 붙여넣기 | 프롬프트 + 링크 제출 |
| 5 산출물 검토 | 결과 요약 먼저 저장하도록 안내 | 요약 → AI 검토 → 한계 추가 |
| 6 발표 | 드롭다운으로 발표자 지정 (4명 순회) | 발표자 설계서 + 검토관 질문 |
| 7 정리 | 4명의 takeaway를 한 화면에서 낭독 | takeaway 입력 |

**게이트 승인 버튼은 AI·자기·동료 검토 3종이 모두 끝나야 활성화된다.** 시간이 밀리면
카드의 체크 표시를 보고 누가 어디서 막혔는지 바로 파악할 수 있다.

## 2. 문제가 생기면

| 증상 | 대응 |
|---|---|
| AI 검토가 실패·지연 | 화면의 **다시 시도** 버튼. 두 번 실패하면 **강사 검토로 대체** — 강사가 구두로 피드백하고 게이트 승인 |
| 수강생이 다른 이름을 눌렀다 | 화면 우측 상단 **이름 바꾸기** |
| 화면이 "세션이 열리지 않았습니다" | 강사가 아직 세션을 안 만들었거나 새로 만든 직후. 새로고침 |
| 설계서 입력이 저장 안 된 것 같다 | 입력칸 밖을 한 번 클릭하면 즉시 저장된다 ("저장됨" 표시 확인) |
| 시간이 부족하다 | 5단계(산출물 검토)를 건너뛰고 6단계 발표로. 단계 버튼은 순서와 무관하게 아무 데나 갈 수 있다 |

## 3. 절대 하지 말 것

- 진행 중 **새 세션 만들기** 클릭 — 수강생 전원이 이름 선택 화면으로 돌아가고 작성 내용이 새 세션에는 없다. (이전 세션 데이터는 Firestore에 남아 있으므로 완전 손실은 아니다)

## 4. 행사 후

- `firestore.rules` 파일 하단의 "행사 후" 블록으로 규칙을 교체해 데이터베이스를 잠글 것.
- **Canva 팀 초대 링크를 재발급할 것.** 배포된 페이지의 자바스크립트에 초대 토큰이
  들어가 있어, 주소를 아는 사람은 누구나 강사의 Canva Pro 팀에 참여할 수 있다.
  Canva → 팀 설정 → 초대 링크 재설정.
